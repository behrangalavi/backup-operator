Configuration model
  Backups are declared with CustomResources (backup.mogenius.io/v1alpha1):
    BackupSource       what to dump, when, retention, analyzer, verification
    BackupDestination  where to upload (sftp / ftps / s3 / azure / gcs)
    BackupRecipient    an age public key every dump is encrypted to
  Only credentials live in Secrets, referenced by name from the CR spec.
  Only PUBLIC age keys are stored in the cluster — keep the private key
  offline; it is the only way to decrypt a backup.

  kubectl -n {{ .Release.Namespace }} get backupsources,backupdestinations,backuprecipients

Management UI (port {{ .Values.ui.port }})
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "backup-operator.fullname" . }} {{ .Values.ui.port }}:{{ .Values.ui.port }}

  exposing it beyond port-forward.

Migrating from the labelled-Secret model (pre-CRD releases)
  Secrets labelled backup.mogenius.io/role are no longer read. Convert them
  once with the restore CLI:
    backup-restore migrate -n {{ .Release.Namespace }} --age-secret {{ include "backup-operator.fullname" . }}-age           # print
    backup-restore migrate -n {{ .Release.Namespace }} --age-secret {{ include "backup-operator.fullname" . }}-age --apply   # create

Restore
  backup-restore --destination <BackupDestination> -n {{ .Release.Namespace }} --target <source> --list
  backup-restore --destination <BackupDestination> -n {{ .Release.Namespace }} --target <source> --age-key ~/age.key --decompress | psql ...
