# 0142. Chart: templated with tests, `[Ingress, Egress]` NetworkPolicy, release reuses the PR gate

**Status:** Accepted. Written under the labelled-Secret model; Secret/annotation names map to CRD fields as listed in [the mapping](README.md#pre-crd-names).

helm-unittest suites (RBAC gating, CRD keep annotation, NetworkPolicy variants, worker env JSON, bootstrap recipients) caught a real bug the moment they ran: `{{ .Values.x | default true }}` turns an explicit `false` into `true`, so `crds.install=false`, `crds.keep=false` and `networkPolicy.worker.enabled=false` were impossible to express — now `hasKey` checks. The NetworkPolicy gained ingress rules (metrics from the monitoring namespace, UI/docs only from `ui.allowedFrom`, default denied) and a worker-pod policy, because the operator policy alone left the UI open to every pod and the credential-holding workers unrestricted. `release.yaml` calls `ci.yaml` via `workflow_call` instead of re-implementing a weaker subset, and adds Trivy (HIGH/CRITICAL) plus cosign keyless signatures for image and chart; base images are digest-pinned; `renovate.json` finally points at `charts/**`, the Dockerfile and the CI tool pins instead of a `kubernetes/` directory that never existed.
